# 📝 Руководство по добавлению задач

> **Базовые правила:**
> * Все задачи проекта хранятся в файле `tasks.json`.
> * Каждое новое задание нужно добавлять в массив `tasks`.
> * **Не изменяйте** названия существующих полей!
> * **Не удаляйте** уже добавленные задания!
> * Используйте исключительно **уникальные ID**!
> * Соблюдайте форматирование JSON!

---

## Структура задания

Каждое задание состоит из следующих полей:

| Поле | Описание |
| :--- | :--- |
| **`id`** | Уникальный числовой идентификатор задачи |
| **`type`** | Тип задания (см. ниже) |
| **`difficulty`** | Сложность задания (см. ниже) |
| **`topic`** | Тема задания |
| **`question`** | Текст задания |
| **`options`** | Варианты ответов |
| **`answers`** | Правильные ответы |
| **`tolerance`** | Допустимая погрешность для числового ответа |
| **`explanation`** | Объяснение правильного ответа |

---

## ⚙️ Допустимые значения

### Типы заданий (`type`)
* `choice` — выбор одного правильного ответа.
* `number` — ввод числового ответа.
* `text` — ввод текстового ответа.

### Уровни сложности (`difficulty`)
* `easy` — легкий.
* `medium` — средний.
* `hard` — сложный.

---

## Правила заполнения полей

### Поле `id`
* Используйте только положительные целые числа.
* Каждое задание должно иметь уникальный ID.
* Не меняйте ID существующих заданий.

### Поле `topic`
* Указывайте основную тему задания, например: `math`, `physics`, `programming`, `chemistry`.

### Поле `options`
* **Обязательно** используем квадратные скобки, даже если нам не нужно проверять введенный с клавиатуры текст.
* Указываем все варианты в кавычках, через запятую.
* *Пример:* `["1", "2", "3"...]`

### Поле `answers`
* Здесь указываем правильный ответ.
* Допускается использовать несколько правильных вариантов, если правильный ответ один (для учета разных регистров или синонимов).
* *Пример:* `["Earth", "earth", "Земля", "земля"]`

### Поле `tolerance`
* Вписываем допустимую погрешность (`tolerance = 0.5` значит допускается отклонение от числа на 0.5).
* В заданиях, не требующих числового ответа, вписываем `0`.

---

## Как добавить свое задание

> Шаблоны с заданиями хранятся в файле `tasks.json`.

1. Откройте файл `tasks.json` в репозитории GitHub.
2. Найдите конец массива `tasks`.
3. Добавьте запятую после предыдущего задания.
4. Добавьте задание согласно шаблону.
5. Проверьте уникальность `ID`.
6. Сохраните изменения через коммит.

---

##  Правила содержания заданий

* Задания должны быть **недвусмысленными** (если это не задачи на логику).
* Задания должны иметь **проверяемый ответ**.
* Задания **не должны содержать** орфографических, грамматических или пунктуационных ошибок.
* Задания **не должны дублировать** предыдущие задания.
* Если задание подразумевает несколько вариантов ответа, **обязательно добавьте их в `answers`**.
